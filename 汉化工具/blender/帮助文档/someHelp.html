Retera Model Studio 汉化版 · 帮助

本页只介绍软件当前真实存在的功能。快捷键以 Blender 习惯为参考。

二、变换：G / R / S

操作快捷键说明
移动G进入移动状态，鼠标移动即跟随变换
旋转R进入旋转状态
缩放S进入缩放状态
锁定单轴变换中按 X / Y / Z只沿该世界坐标轴变换，鼠标拖拽只影响该轴
排除单轴Shift + X/Y/Z在另外两个轴上变换
取消轴约束再按一次同一轴键回到自由变换
数字精确输入变换中直接输入数字，回车 确认移动为距离，旋转为角度（度），缩放为倍数（1 = 100%）
确认变换左键点击提交并写入撤销记录
取消变换右键 / Esc还原到变换前

注意：当前 XYZ 轴锁定使用世界坐标轴。局部坐标（随骨骼旋转的轴）切换尚未实现，界面上也不会假装支持。

三、编辑模式选择

操作快捷键说明
顶点 / 面 / 组 / 动画模式工具栏按钮（按钮上带有快捷键）决定当前选择的是什么类型的元素
拓扑关联选择L（顶点模式）鼠标指向某个顶点按 L，选中与它通过三角面顶点相连的整块连通区域

四、添加粒子（含丝带）

  1. 菜单 添加 → 粒子，选择内置粒子模板，或选择 空丝带粒子（Ribbon） 直接新建一条丝带。
  2. 对话框里的 父级 下拉框可以直接输入文字过滤，例如输入 weapon、hand 快速定位骨骼，不必在几百个骨骼里滚动。
  3. 坐标三个输入框的含义：
    输入框含义坐标轴
    X前后方向红色轴
    Y左右方向绿色轴
    Z上下方向蓝色轴
    修改时对话框底部会实时显示当前坐标值。
  4. 丝带与爆米花粒子的区别：丝带（RibbonEmitter）是连续条带，适合刀光、拖尾；爆米花（ParticleEmitter2）是独立小面片，适合火花、烟尘。

五、时间轴

时间轴默认是禁用状态，连播放按钮都不显示。要看到动画，请按顺序做：① 按 A 或点工具栏「动画」模式按钮进入动画编辑模式；② 确认模型本身带有动画序列（动画下拉框显示 (Unanimated) 就是没有，纯静态的武器 / 道具模型通常没有动画）；③ 在下拉框里选一个序列；④ 按 Ctrl + 空格 播放。另外「视图」菜单里的「渲染粒子」要勾选，否则粒子不显示。

操作说明
拖动蓝色滑块改变当前时间；滑块两侧的小箭头可逐帧微调
拖动关键帧方块改变关键帧时间，松开后写入撤销记录

六、界面说明

  • 按钮统一为 Blender 风格直角矩形，工具栏按钮直接写中文和快捷键，例如“移动 G”“旋转 R”。
  • 鼠标悬停在控件上会显示中文气泡说明。
  • 左侧“大纲视图”与视口联动：在视口点选骨骼，节点树会自动展开并高亮对应节点。

七、把外部模型（剑）挂到手部

先弄清一个概念：魔兽 3 的附着点（界面里叫「附着点」，英文 Attachment）是给游戏引擎用的空定位点，不是编辑器里「引用另一个模型文件」的对象。所以有两条完全不同的路，按目标选。

路线 A：游戏里按附着点名自动挂载（WC3 标准做法）

  1. 菜单 添加 → 附着点 新建一个附着点。
  2. 在「模型组件」面板把名字改成标准英文：Hand Right、Weapon、Hand Right Ref 等。名字必须保留英文，写中文游戏端识别不了。
  3. 把父级设成手部骨骼（面板里的 Parent + change 按钮）。
  4. 剑模型不需要塞进 RMS：由单位数据或 MDL 的 Path 属性在游戏运行时按附着点名挂上去。数据层有 path 字段，但本编辑器没有对应的输入框，要写只能手工改 MDL 文本。

路线 B：把剑的网格真正合并进当前模型

  1. 菜单 工具 → Twilac 实验工具 → 导入模型部件，选择剑的 .mdx / .mdl 文件。
  2. 在 父级（Parent） 里选手部骨骼。注意这个选择器只能选骨骼，不能选附着点对象。
  3. 点「导入！」，剑的骨骼链与几何体会并入当前模型，之后可以像普通网格一样编辑。

另外 文件 → 导入（Ctrl+Shift+I）也能合并组件 / 动画，但结果会打开一个新窗口，别盯着旧窗口以为没生效。常规模型对话框只支持 MDX / MDL，不含 FBX / OBJ。

八、给剑做丝带刀光（拖尾）

  1. 菜单 添加 → 粒子 → 空丝带粒子（Ribbon）。
  2. 空丝带不会弹父级选择框，默认挂在原点：去节点树把它挂到武器 / 手部骨骼，并给它位移动画，或绑定到会挥砍的骨骼。没有位移动画就没有拖尾。
  3. 选中丝带节点，「模型组件」面板可调：上方高度 / 下方高度（拖尾宽度）、生命周期（尾段长度）、发射速率、重力、不透明度、颜色、贴图行数 / 列数 / 格索引。
  4. 材质换成「叠加」+ 带渐变 Alpha 的贴图：先用 工具 → 编辑贴图 添加图片，再回丝带面板的材质下拉选择。
  5. 只在挥砍时显示：给可见性打关键帧，非挥砍帧设为 0（0 = 隐藏，>0 = 显示）。

编辑视口不渲染丝带拖尾。这是上游渲染管线的限制，源码里明确写了「编辑视口未显示拖尾时，请在游戏中查看」。所以编辑器里看不到 ≠ 没做出来，需要导出模型进游戏验证。丝带也没有速度 / 发散角 / 宽度参数，参数量少于粒子发射器 2。更完整的配方见 粒子特效中文教程.html 的「刀光拖尾」一节。

九、贴图与 UV

想做什么用哪个功能说明
换 / 加 / 导出贴图工具 → 编辑贴图增删、改路径、替换、导出；图片查看器是只读预览
调整贴图怎么贴到模型工具 → 编辑 UV 映射编辑顶点 UV 坐标（移动 / 旋转 / 缩放 / 镜像 / 重映射 / 拆分顶点）
在图片上画画（实时绘制纹理）没有见下

本软件没有画笔 / 实时绘制纹理功能。UV 编辑器里的 Load Image 只是把图片垫在背后当对齐参考，「Wrap Image」等显示选项也不修改模型，画上去的像素不会保存。唯一可行的往返流程是：工具 → 编辑贴图 → Export 导出 → 用 Photoshop / GIMP / BLP 工具在外部绘制 → Replace / Add 导回（或改 Apply Path 指向新文件）。

十、当前确实没有的功能

  • 实时绘制纹理 / 贴图笔刷 / BLP 像素写回。
  • 丝带拖尾在编辑视口的实时预览。
  • 建模页的高级建模工具：环切、倒角、细分、布尔、镜像、软选择等。建模「添加」页目前只有顶点、由所选内容创建面、骨骼、平面、立方体，以及「变换」页的数值输入。
  • 局部坐标系（随骨骼旋转的轴）锁定。

如果发现文档与软件不一致，以软件实际行为为准。
