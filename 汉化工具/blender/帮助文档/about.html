Retera Model Studio（RMS）汉化增强版

面向《魔兽争霸 III》模型（.mdx / .mdl）的查看与编辑工具。

版本信息

主程序Retera Model Studio（开源项目 hiveworkshop/ReteraModelStudio）
本版本简体中文汉化 + Blender 风格操作增强（运行时注入）
运行环境Windows，内置 Java 运行时，无需单独安装 JDK

本汉化增强版做了什么

  • 全界面简体中文，包含菜单、工具栏、对话框与悬浮提示。
  • 工具栏改为直角矩形中文按钮，写明快捷键（移动 G、旋转 R、缩放 S、分离面 P、挤出 E）。
  • Blender 风格快捷键：G/R/S/E/P 变换，X/Y/Z 锁轴，数字精确输入，Esc 取消。
  • 编辑模式 L 键拓扑连通选择，Shift+L 叠加。
  • 粒子添加窗口支持父级节点搜索，XYZ 输入框带说明与实时坐标显示，新增“空丝带粒子（Ribbon）”。
  • 视口与左侧节点树双向联动，`.` 键聚焦所选。

尚未实现（避免误导）

  • 局部 / 全局坐标系切换：目前轴锁定只支持世界坐标轴。
  • 时间轴为原版结构 + 刻度与配色优化，不是全新的重写版本；且默认禁用，需先进入「动画」模式。
  • 实时绘制纹理：只有贴图增删替换与 UV 坐标编辑，没有画笔 / 像素写回。请在外部图像编辑器绘制后导回。
  • 丝带拖尾的编辑视口预览：拖尾只在游戏里渲染，编辑器中看不到，需导出验证。
  • 建模页高级工具：环切、倒角、细分、布尔、镜像、软选择等均未提供。
