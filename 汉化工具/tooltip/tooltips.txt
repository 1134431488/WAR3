# Retera Model Studio 中文版 · 悬停功能说明表（内置默认）
# 格式：界面上显示的文字=中文说明||快捷键
#   · "||" 后面是快捷键，可省略；说明里用 \n 表示换行
#   · 菜单项本身带快捷键时，即使这里不写也会自动显示真实组合键
#   · 程序目录下的「提示说明.txt」是此文件的可编辑副本，改完重启程序即生效
#   · 同一个文字在外部表里再写一次，即可覆盖这里的说明
# ============================================================ 主菜单
文件=新建、打开、保存、导入导出模型，以及管理最近使用的文件。
编辑=撤销重做、选择、变换与查找替换等编辑操作，偏好设置也在这里。
视图=控制 3D 视图、面板显示、线框与粒子渲染方式。
窗口=在打开的模型窗口之间切换，或调整窗口排布。
工具=模型优化、法线重算、几何体处理与实验性功能。||部分工具见「Twilac 实验工具」
帮助=打开快捷键速查与程序信息。
脚本=运行内置脚本，批量处理模型。
选项=打开设置项。
常规=常规显示与行为设置。
杂项=其他不常改动的设置。
# ============================================================ 文件操作
新建=创建一个空白模型文件，或从零开始新建组件。||Ctrl + N
打开=从磁盘载入 MDX / MDL / 地图或游戏数据中的模型。||Ctrl + O
打开最近使用=列出最近打开过的模型，点一下即可重新载入。
打开内部文件=浏览魔兽 III 游戏数据包（MPQ / CASC）内部的模型。
保存=把当前模型写回原文件。||Ctrl + S
另存为=换一个路径或文件名保存，不覆盖原文件。||Ctrl + Q
保存地图=把改动写回当前打开的地图文件。
关闭=关闭当前模型窗口。||Shift + Esc
全部关闭=关闭所有打开的模型窗口。
关闭其他=只保留当前模型，关掉其余窗口。
关闭模型=关闭当前模型并释放其编辑状态。
退出=退出程序；有未保存修改时会先提示。
退出 RMS=退出 Retera Model Studio。
强制退出 RMS=不检查未保存内容，直接结束程序；仅在卡死时使用。
导入=把另一个模型的组件或动画合并进当前模型。||Ctrl + Shift + I
导入模型部件=选择另一个模型的部件，追加到当前模型中。
拼接几何体=把两个模型的网格按名称或结构合并。
从文件导入=从磁盘上的模型文件导入内容。||Ctrl + Shift + I
从单位导入=按魔兽 III 单位 ID 直接载入对应模型。||Ctrl + Shift + U
优化=清理未使用的节点、冗余关键帧与重复数据，减小模型体积。

# ============================================================ 模型组件
骨骼=骨骼节点，驱动蒙皮顶点做动画；可挂接其他节点作为子对象。
辅助点=不渲染的辅助节点，常用于定位特效、附着点与发射器。
几何体=模型的一块网格，包含顶点、面、法线与材质归属。
材质=一组渲染层设置，决定几何体的着色与混合方式。
贴图=模型引用的图像文件；路径需为游戏可识别的相对路径。
贴图动画=贴图本身的滚动、旋转或缩放动画。
纹理坐标编辑器=编辑顶点的 UV 坐标，把贴图正确贴到模型表面。
动画=一段命名的时间区间，可循环播放。
动画序列=动画列表，用于增删、重命名与调整播放范围。
全局序列=跨所有动画共享的循环时间轴，常用于粒子与贴图动画。
关键帧=某时间点上记录的数值，相邻关键帧之间会自动插值。||← / →
可见性=控制组件在哪些时间显示：0 隐藏，大于 0 显示。
摄像机=模型内部的摄像机节点，用于过场与特殊视角。
灯光=模型自带的灯光节点。
碰撞体=用于单位选取与碰撞检测的简单几何形状。
附着点=武器、特效等外部对象挂到模型上的定位点；名称必须保留英文。
粒子发射器=经典（第一代）粒子发射器，用一张贴图做点状/片状粒子。
粒子发射器 2=第二代粒子发射器，参数最全，支持子贴图、行列切片与头尾模式。
飘带发射器=沿运动轨迹拉出带状拖尾，常用于刀光、光带。
爆米花发射器=RMS 提供的爆发式粒子发射器，适合一次性爆裂效果。
空爆米花发射器=新建一个不带预设的爆米花发射器。
节点=模型结构树中的一个对象，可以是骨骼、辅助点、发射器等。
组件=模型结构树中可编辑的组成部分。
# ============================================================ 粒子参数
粒子名称：=给新建的发射器命名，建议使用英文以免导出后游戏识别异常。
父级：=指定发射器挂到哪个骨骼/辅助点上；发射器会跟随父节点运动。
无父级=不挂接任何节点，发射器固定在模型原点。
选择颜色=设置粒子在生命周期中的颜色关键帧。
选择贴图=从模型贴图列表里挑一张作为粒子贴图。
粒子缩放=粒子从生成到消失的大小变化曲线，可做「先胀大再消散」。
发射速率=每秒生成多少个粒子；越大越密，过大容易掉帧。
速度=粒子离开发射器时的初速度。
变化=给速度与方向加入随机扰动，避免粒子排成整齐一条线。
变化（%）=给速度与方向加入随机扰动的百分比。
纬度=发射锥体的张角：0 为一条直线，数值越大越向四周发散。
经度=绕发射轴的旋转扩散角度，仅第一代粒子发射器使用。
重力=粒子受到的向下加速度；设负值可做出上飘的烟与火花。
生命周期=单个粒子存活时间，界面单位约为 0.1 秒。
生命跨度=单个粒子存活时间。
长度=粒子贴片的长度，或拖尾的纵向长度。
优先级平面=决定粒子与模型其他部分的绘制先后顺序；数值不当会被模型遮住。
过滤模式=粒子贴图与背景的混合方式。
混合=普通透明混合，适合烟、雾、云。
叠加=颜色直接相加，适合火焰、光效，越叠越亮。
调制=与背景相乘，适合暗化与阴影。
调制 2 倍=调制的加强版。
透明度键=用贴图 Alpha 通道决定透明区域。
头=粒子只在头部显示贴图。
尾=粒子只在尾部显示贴图。
两者=头尾都显示贴图。
头尾=选择粒子贴图显示在头部、尾部还是两者。
混合时间=粒子颜色/透明分段之间的过渡时间。
行数=把贴图按行切分的格数。
列数=把贴图按列切分的格数。
子贴图：=贴图被切成的网格；每个粒子随机取用其中一格，可做出多种形状。
尾长=拖尾粒子的长度。
时间（%）=粒子生命周期进度，用于定位颜色/透明/缩放分段。
头部 UV（子贴图索引）=指定头部使用贴图中的哪一格。
尾部 UV（子贴图索引）=指定尾部使用贴图中的哪一格。
开始=该分段的起始时间点。
结束=该分段的结束时间点。
重复=贴图分段是否循环取用。
衰减=粒子在尾段逐渐变淡或变小的程度。
透明度=粒子的不透明度，0 为全透明，255 为不透明。
颜色=粒子显示的颜色，可随时间打关键帧。
标志=粒子发射器的渲染开关集合。
不受光照=粒子不受场景光照影响，始终保持贴图原色。
不受雾影响=粒子不受场景雾化影响，远处依然清晰。
线发射器=沿一条线发射粒子，而不是从一个点。
模型空间=粒子坐标跟随模型空间，模型移动时一起移动。
XY 四边形=粒子始终以 XY 平面四边形绘制。
喷射=喷射式发射标志。
添加为新发射器=用当前参数另建一个发射器，不改动原发射器。
编辑粒子发射器 2=打开完整参数面板，编辑第二代发射器的全部字段。
选择一个发射器=先在模型结构树里点选一个粒子发射器，再来编辑参数。
新建爆米花发射器=添加一个爆发式粒子发射器。
导出=把当前发射器或粒子设置导出为文件。
