# ============================================================ 主菜单

编辑=撤销重做、选择、变换与查找替换等编辑操作，偏好设置也在这里。

# ============================================================ 模型组件
骨骼=骨骼节点，驱动蒙皮顶点做动画；可挂接其他节点作为子对象。
辅助点=不渲染的辅助节点，常用于定位特效、附着点与发射器。
几何体=模型的一块网格，包含顶点、面、法线与材质归属。
材质=一组渲染层设置，决定几何体的着色与混合方式；丝带/拖尾面板里这里选的是拖尾用的贴图材质。
贴图=模型引用的图像文件；路径需为游戏可识别的相对路径。
贴图动画=贴图本身的滚动、旋转或缩放动画。
纹理坐标编辑器=编辑顶点的 UV 坐标，把贴图正确贴到模型表面。
动画=一段命名的时间区间，可循环播放。
动画序列=动画列表，用于增删、重命名与调整播放范围。
全局序列=跨所有动画共享的循环时间轴，常用于粒子与贴图动画。
关键帧=某时间点上记录的数值，相邻关键帧之间会自动插值。||← / →
可见性=控制组件在哪些动画里显示：0 = 隐藏，1 = 显示。编辑器视口的显示阈值是 0.75，设 0.5 仍可能看起来像隐藏。
摄像机=模型内部的摄像机节点，用于过场与特殊视角。
灯光=模型自带的灯光节点。
碰撞体=用于单位选取与碰撞检测的简单几何形状。
附着点=武器、特效等外部对象挂到模型上的定位点；名称必须保留英文。
粒子发射器=第一代粒子发射器：用一张贴图喷出点状/片状粒子，参数较少，靠外部模型文件驱动。
粒子发射器 2=第二代粒子发射器：最常用、参数最全，支持贴图切格、头尾显示与多种混合方式。
飘带发射器=丝带发射器，沿节点运动轨迹拉出一条带状拖尾，专门用来做刀光、光带。菜单里叫「空丝带粒子（Ribbon）」。
爆米花发射器=爆发式粒子发射器，适合一次性爆裂、碎片四散的效果。
空爆米花发射器=新建一个不带任何预设的爆米花发射器，材质和数值都要自己配。
节点=模型结构树中的一个对象，可以是骨骼、辅助点、发射器等。
组件=模型结构树中可编辑的组成部分。
# ============================================================ 粒子参数（大白话版）
# 说明写法：这个参数控制什么 → 调大/调小会怎样 → 举例。鼠标悬停即可看到。
粒子名称：=给新建的发射器起个名字。建议用英文，导出后游戏更容易识别。
父级：=让发射器挂在哪个骨骼或辅助点上，之后会跟着这个节点一起动。做刀光就挂到武器/手部骨骼。
无父级=不挂任何节点，发射器固定在模型原点；这样通常拉不出拖尾。
选择颜色=设置粒子「出生 / 中间 / 消失」三个阶段的静态颜色，不是关键帧。
选择贴图=从模型贴图列表里挑一张图当粒子外观。带透明渐变的图最适合做刀光。
粒子缩放=控制粒子从出生到消失的大小变化，可以做出「先胀大再消散」。
发射速率=每秒喷出多少个粒子。调大更密、更亮，太大容易掉帧。例：40 = 每秒 40 个。
速度=粒子刚飞出发射器时有多快。调大飞得更远、更散。
变化=给速度和方向加随机抖动（界面也写作「变化（%）」，数值是百分比），避免粒子排成整齐一条线；0 = 完全整齐，100 = 抖动最大。
纬度=发射锥的张角：0 = 一条直线，调大就向四周散开（像喷头调雾状）。
经度=绕发射轴一圈的扩散角度，只有第一代粒子发射器用到。
重力=粒子往上飘还是往下掉。正数往下坠（雨、火花），负数往上飘（烟、火焰）。
生命周期=单个粒子从出生到消失能活几秒，单位是「秒」。调大尾巴拖得更长。例：1 = 存活 1 秒。
生命跨度=单个粒子能活几秒，和「生命周期」是同一个意思。
长度=粒子贴片或拖尾的纵向长度。
优先级平面=决定粒子画在模型前面还是后面。数值不对会被模型挡住看不见。
过滤模式=粒子贴图怎么和背景混合，直接决定「亮不亮、透不透」。
混合=普通透明混合，适合烟、雾、云。
叠加=颜色直接相加，越叠越亮，适合火焰、刀光、光效。
调制=与背景相乘让画面变暗，适合阴影。
调制 2 倍=变暗效果加倍的调制。
透明度键=用贴图的透明通道把不需要的部分抠掉，避免出现白色方块。
头=只在粒子头部显示贴图。
尾=只在粒子尾部显示贴图。
两者=头部和尾部都显示贴图。
头尾=选择贴图出现在粒子的头、尾还是两端都有。
混合时间=颜色/透明分段的中点位置（占生命进度的百分比），不是过渡时长。例：50 = 活到一半时切换。
行数=把一张贴图横着切成几行格子。1 = 不切。
列数=把一张贴图竖着切成几列格子。1 = 不切。
子贴图：=贴图切成的小格子。粒子按出生顺序依次使用，不是随机抽取；可做出多段不同形状。
尾长=拖尾粒子的长度，调大尾巴更长。
时间（%）=粒子生命走到百分之几，用来定位颜色/透明/缩放的分段点。
头部 UV（子贴图索引）=粒子头部用贴图里的第几格，从 0 开始数。
尾部 UV（子贴图索引）=粒子尾部用贴图里的第几格，从 0 开始数。
开始=这一段的起始生命进度。
结束=这一段的结束生命进度。
重复=贴图格子是否循环着用。
衰减=粒子到尾段逐渐变淡或变小的程度，调大尾巴消失得更柔和。
透明度=粒子的不透明度，范围 0～1：0 完全透明，1 完全不透明，0.5 半透明。
颜色=粒子显示的颜色，可以随时间打关键帧。
标志=粒子发射器的渲染开关集合。
不受光照=粒子不受场景灯光影响，始终保持贴图原本亮度。
不受雾影响=粒子不受场景雾影响，远处也看得清。
线发射器=沿一条线发射粒子，而不是从一个点喷。
模型空间=粒子坐标跟随模型，模型移动时粒子一起移动。
XY 四边形=粒子始终以 XY 平面的四边形绘制。
喷射=间歇式一股一股地喷，而不是连续喷。
添加为新发射器=用当前参数另建一个发射器，原来的那个不变。
编辑粒子发射器 2=打开完整参数面板，编辑第二代发射器的全部字段。
editParticle=打开粒子发射器 2 的完整参数面板，可调整这里没列出的高级参数。
选择一个发射器=先在左侧模型结构树里点选一个粒子发射器，再回来调参数。
新建爆米花发射器=添加一个爆发式粒子发射器，适合一次性爆裂效果。
空爆米花粒子=新建一个空的爆米花发射器（不带预设贴图与参数），需要自己配材质和数值。
空丝带粒子=新建一条空丝带（拖尾）发射器。注意：它默认挂在模型原点，必须自己去节点树里挂到武器/手部骨骼并加位移动画，否则看不到拖尾。
丝带发射器=沿节点运动轨迹拉出带状拖尾，常用来做刀光、光带。也叫「飘带发射器」。
# ---- 丝带（刀光）专属参数：之前完全没有说明 ----
上方高度=拖尾往「上」伸出多宽。和下方高度一起决定刀光总宽度；两个都设 24 约为中等宽度。
下方高度=拖尾往「下」伸出多宽。和上方高度一起决定刀光总宽度。
贴图行数=把贴图切成几行格子，配合「贴图格索引」选图；1 = 用整张图。
贴图列数=把贴图切成几列格子，配合「贴图格索引」选图；1 = 用整张图。
贴图格索引=用贴图里的第几格，从 0 开始数。格子总数 = 行数 × 列数，别超过这个数。
不透明度=拖尾有多不透明，范围 0～1：0 全透明，1 全不透明。做刀光建议配合带渐变的贴图。
丝带颜色=拖尾的颜色，会与贴图颜色相乘；想保留贴图原色就设为白色。
未命名材质=这个丝带还没指定材质，请在下拉框里选一个，否则看不到拖尾。
