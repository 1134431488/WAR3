先建立三个概念： ① 发射器是模型里的一个节点，本身不可见，负责「按规则吐粒子」； ② 贴图是每个粒子长什么样（一张带透明通道的图片）； ③ 关键帧决定粒子在一生中何时变色、变大、变淡、以及发射器在哪些动画里开启。
做特效 = 选发射器 → 给贴图 → 调发射规则 → 打关键帧 → 挂到正确的骨骼上。

一、三分钟上手：照着做一遍

第 1 步 · 打开模型
用「启动汉化版.bat」打开程序，文件 → 打开（Ctrl+O）载入一个 MDX/MDL 模型；或 文件 → 新建 从空模型开始练习。
第 2 步 · 添加一个发射器
在模型组件树（左侧结构树）里右键，从「添加 / 新建」类菜单里选择粒子相关项。程序内置了一个带图标预览的粒子预设面板（界面上有「粒子名称：」「父级：」「无父级」和 X / Y / Z 三个坐标框），可以从游戏自带特效里挑一个作起点，也可以直接「新建爆米花发射器」从零开始。
第 3 步 · 挂到骨骼上
在「父级：」下拉里选一个骨骼或辅助点（例如手部、武器、头顶）。选「无父级」时发射器固定在模型原点，模型转身、挥武器时粒子不会跟着走。坐标 X / Y / Z 用来微调发射位置。
第 4 步 · 给一张贴图
选中刚建好的发射器，在右侧属性面板里找到贴图下拉框，选一张模型贴图列表里的图。想用新图片，先 编辑贴图 → 添加贴图，把带 Alpha 通道的 BLP / TGA / PNG 加进模型，再回来选它。
第 5 步 · 调四个最关键的数
发射速率（密度）、速度（飞多快）、重力（向上飘还是往下掉）、生命周期（活多久）。先只动这四个，边改边看 3D 视窗。
第 6 步 · 打开完整参数面板
属性面板上有一个 editParticle 按钮，可打开 编辑粒子发射器 2 完整面板；这是目前唯一可用的入口（「工具 / Twilac 实验工具」里并没有粒子编辑器）。那里能设置过滤模式、头尾显示、子贴图行列、颜色与缩放分段。改完点「应用」才写回模型；点「添加为新发射器」则是用这套参数另建一个，不动原来的。
第 7 步 · 保存并到游戏里验证
文件 → 保存，把模型和贴图一起导入地图 / MPQ，进游戏看效果。编辑器里好看 ≠ 游戏里好看，最后一步不能省。
新手最容易漏的一步：发射器的可见性关键帧。如果当前动画帧上可见性是 0，参数调得再漂亮也一个粒子都看不到。先在时间轴里确认发射器处于显示状态。

二、四种发射器，该用哪个

类型（界面中文）模型内部名特点与适用场景
粒子发射器ParticleEmitter第一代，参数少（经度、纬度、速度、重力、发射速率、可见性）。老地图里最常见，兼容性最好，适合简单火花、灰尘。
粒子发射器 2ParticleEmitter2做特效首选。支持子贴图切片、行列、头尾模式、颜色/透明/缩放分段、多种过滤模式与渲染标志。火焰、烟、雪、光柱基本都用它。
飘带发射器RibbonEmitter沿节点运动轨迹拉出一条连续色带，用于刀光、剑气、拖尾。菜单里叫「空丝带粒子（Ribbon）」，也叫飘带发射器。属性面板可调：上方/下方高度（拖尾宽度）、生命周期（尾巴多长）、发射速率、重力、不透明度、丝带颜色、贴图行列与格索引、材质。注意：编辑视口不渲染拖尾，要导出进游戏才看得见；节点必须有位移动画。
爆米花发射器PopcornEmitter
RMS 扩展类型		爆发式/一次性粒子，参数含生命周期、发射速率、速度、透明度、颜色、可见性与状态（State）。适合击中爆裂、瞬间迸射。注：旧版本这些参数在面板上没显示出来，现已修复。

注：模型内部名与附着点名称一律保留英文，这是魔兽 III MDX/MDL 的硬性要求，汉化版不会翻译它们。

三、在界面里找到粒子功能

  • 添加入口：带图标预览的粒子预设面板（「粒子名称：」「父级：」「无父级」「X / Y / Z」），以及「新建爆米花发射器」。
  • 结构树：所有发射器都以节点形式出现在模型组件树里，点选即可编辑；右键菜单里还能编辑可见性、重命名、删除。
  • 精简属性面板：选中节点后右侧显示，第二代发射器能看到 宽度 / 长度 / 纬度 / 变化 / 速度 / 重力 / 发射速率 / 可见性 与贴图下拉；第一代多了「经度」；爆米花是 生命周期 / 发射速率 / 速度 / 透明度 / 可见性 / 颜色 并带「导出」按钮（旧版本这六个参数没被加进界面，现已修复）。
  • 完整编辑面板：「编辑粒子发射器 2」——参数最全，见下一节。
  • 实验工具面板（Twilac's new tools）：除粒子外还有法线、吸附顶点、几何体可编辑性、编辑键位等工具。
  • 显示开关：偏好设置里的「渲染粒子 / 渲染粒子发射器：」，控制 3D 视窗是否绘制粒子。

四、参数速查（按实际面板分组）

4.1 发射规则

界面参数内部字段作用与调法
发射速率EmissionRate每秒生成多少粒子。调大变密；过高会掉帧，一般先从小值往上试。
速度Speed粒子离开发射点的初速度。配合「变化」才不会像一条整齐的直线。
变化 / 变化（%）Variation给速度与方向加随机扰动。烟雾、火星要开大；光柱、射线要设 0。
纬度Latitude发射锥体的张角。0 = 一条直线，越大越向四周散开。
经度Longitude绕发射轴的扩散角，主要出现在第一代粒子发射器面板。
重力Gravity向下的加速度。负值让粒子上飘（火焰、烟），正值下落（雨、雪、碎屑）。
生命周期 / 生命跨度LifeSpan单个粒子存活时间，单位是秒（例：1 = 活 1 秒）。完整面板的滑块为了好拖动把数值放大 10 倍显示，所以标成 LifeSpan (~ 0.1 s)；但存进模型的真实单位仍是秒，不要按 0.1 秒去换算。
宽度 / 长度Width / Length粒子贴片的尺寸，或拖尾的长宽。
尾长TailLength拖尾段的长度。
时间（%）Time粒子生命期进度，用于定位颜色/透明/缩放分段的起止。

4.2 外观与混合

界面参数内部字段作用与调法
过滤模式：混合Blend普通透明混合。烟、雾、云、灰尘用它。
过滤模式：叠加Additive颜色直接相加，越叠越亮。火焰、光效、能量用它；需要贴图带透明通道。
过滤模式：调制 / 调制 2 倍Modulate / Modulate2x与背景相乘，用于阴影、暗化效果。
过滤模式：透明度键AlphaKey用贴图 Alpha 决定哪些像素被剔除，边缘偏硬。
头 / 尾 / 两者HeadOrTail贴图显示在粒子的头部、尾部，还是两处都显示。
头部 UV / 尾部 UV（子贴图索引）Head UV / Tail UV指定头尾各自取用贴图中的哪一格。
子贴图：行数 / 列数Rows / Columns把一张贴图切成网格。粒子按生命进度依次使用各格（不是随机抽取），一张图就能做出分段变化的形状；配合「头部 UV / 尾部 UV」指定起止格。
优先级平面PriorityPlane绘制先后顺序。粒子被模型挡住时，先调它。
颜色 / 选择颜色SegmentColor粒子在生命期中的颜色分段，可做「橙 → 红 → 暗」的火焰渐变。
透明度Alpha / SegmentAlpha不透明度分段，0 全透明。淡入淡出靠它。
粒子缩放SegmentScaling大小随时间变化：先胀大再消散，或持续缩小。
开始 / 结束 / 重复 / 衰减start / end / repeat / Decay分段的起止点、是否循环、以及尾段变淡变小的程度。
混合时间Blend Time颜色/透明分段的中点位置（占生命进度的百分比），不是过渡时长。

4.3 渲染标志（完整面板里的 Flags 区）

标志说明
Unshaded 不受光照粒子不吃场景光照，保持贴图本色。发光类特效一般勾上。
Unfogged 不受雾影响远处不被雾遮淡。
LineEmitter 线发射器沿一条线发射，而不是从一个点。
SortPrimsFarZ改变粒子的深度排序方式，处理半透明穿插问题。
ModelSpace 模型空间粒子坐标跟随模型空间，模型移动时一起移动。
XYQuad XY 四边形始终以 XY 平面四边形绘制。
Squirt 喷射喷射式发射行为。
「应用」与「添加为新发射器」的区别
应用 = 把当前参数写回你选中的那个发射器（改原对象）。
添加为新发射器 = 用当前参数复制出一个新发射器（原对象不变）。做 A/B 对比时特别好用。

五、关键帧：让粒子动起来、变色、消失

凡是右侧带数值框又能在时间轴上打点的参数（发射速率、速度、重力、可见性、颜色、透明度、缩放），本质都是一条动画轨道。程序里用浮点轨道（FloatAnimFlag）与颜色/向量轨道（Vec3AnimFlag）存储。

  1. 把时间轴拖到想要的帧（→ 跳下一个关键帧、↑ / ↓ 逐帧移动）。
  2. 改数值，程序会在该帧记录一个关键帧；相邻关键帧之间自动插值。
  3. 按 Ctrl + 空格 播放，观察整段动画里的变化。
轨道典型用法
可见性 Visibility让特效只在「攻击」「施法」这类动画里出现。数值 0 = 隐藏，1 = 显示；编辑器视口的显示阈值是 0.75，设 0.5 仍可能看起来是隐藏的。这是特效与动画配合的核心。
发射速率爆发瞬间拉高、随后归零，做出「喷一下就停」的效果。
颜色 / 透明度火焰由亮黄转暗红再淡出；烟雾越飘越淡。
缩放生成时小 → 中期变大 → 消散时缩回，或直接持续放大做膨胀烟团。

提示：编辑键位可在「编辑 → 偏好设置窗口 → 快捷键 → 编辑快捷键」里查看全部可绑定动作；完整列表见程序内「帮助 → 快捷键速查」，本汉化版已把它做成中文页。

六、六种常用效果配方

下面是调参方向，不是固定答案。建议先照方向设一遍，再边播放边微调。

效果发射器关键设置
火焰粒子发射器 2叠加 过滤模式；颜色橙黄 → 红 → 暗；重力设负值让火苗上飘；生命周期短、发射速率高、纬度小；缩放随时间递减；勾「不受光照」。
烟 / 雾粒子发射器 2混合；灰白色；小幅负重力 + 大变化值让烟散开；生命周期长、速度低；透明度淡入再淡出；缩放持续变大。
落雪 / 灰尘粒子发射器 2混合；白色小贴图；重力正值、速度低、变化中等；发射速率低、生命周期长；纬度调大覆盖一片区域。
光柱 / 射线粒子发射器 2叠加；纬度 0、变化 0（保持一条直线）；长度拉大、宽度收窄；颜色偏亮；生命周期短，配合可见性关键帧做瞬间闪光。
刀光拖尾丝带发射器（菜单：空丝带粒子）发射器挂到武器骨骼/手部辅助点；叠加 + 带渐变 Alpha 的贴图；透明度尾段衰减；只在挥砍动画中把可见性打开。
击中爆裂爆米花发射器发射速率高、生命周期极短、速度大、纬度大（四面八方散开）；颜色亮 → 快速淡出；可见性只在命中那一两帧打开。

七、看不到粒子？常见问题排查

症状检查顺序
编辑器里完全没有粒子① 偏好设置里的「渲染粒子 / 渲染粒子发射器：」是否开启；② 当前动画帧的可见性是否为 0；③ 发射速率是否为 0；④ 发射器是否被父节点隐藏。
粒子是黑色方块 / 白底方块贴图没有 Alpha 透明通道，或过滤模式选错。发光类改 叠加，烟雾类改 混合；换一张带透明通道的 BLP / TGA / PNG。
编辑器正常，游戏里看不到贴图路径必须是游戏能识别的相对路径（如 Textures\xxx.blp），且贴图文件要随模型一起打进地图 / MPQ；检查导出时贴图是否被一起导出；检查优先级平面是否被模型遮住。
粒子不跟着模型/武器动「父级」设成了「无父级」，或挂错骨骼。把发射器挂到对应骨骼或辅助点上；需要跟随模型整体运动时勾 ModelSpace。
改了参数没变化完整面板改完要点「应用」；若点的是「添加为新发射器」，改动落在了新对象上，请看结构树里选中的是不是你以为那个。
一开特效就卡发射速率过高、贴图分辨率过大、生命周期过长导致同屏粒子堆积。先降发射速率，再缩短生命周期。
导出后名称乱码 / 游戏报错发射器、骨骼、辅助点等内部名称建议只用英文与数字。界面上的中文标签不会写进模型文件，但手动输入的对象名会。
