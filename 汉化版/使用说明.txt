Retera Model Studio 中文版 · 使用说明
========================================

【启动】
双击「启动汉化版.bat」即可。程序自带便携 Java 17 运行时（runtime 目录），
电脑上没装 Java 也能用。出问题时改用「启动汉化版_调试模式.bat」，
会保留黑色控制台窗口，方便查看报错信息。

【首次运行】
第一次启动会弹出「Setup」设置窗口，要求指定魔兽争霸 III 的安装目录。
这是原程序的行为，不是汉化造成的：
  · 装了重制版 / 经典版：点「添加魔兽 III 安装目录」选择游戏目录；
  · 只想先看看界面：直接点「取消 / 确定」也能进主界面；
  · 日志里出现 MPQ 图标找不到的提示属正常现象，配置好游戏目录后即消失。

【这次新增了什么】
1. 界面汉化：菜单、按钮、面板、提示文字、内置快捷键速查页、单位颜色名称。
   词典 1028 条，改写 453 个界面 class、1758 处字符串。
2. 中文悬停说明气泡：鼠标停在任意菜单项、工具按钮、标签或页签上，
   稍等片刻会弹出该功能的中文说明；菜单项还会自动附带真实快捷键。
   实测一次运行为 900+ 个组件注入了气泡，气泡弹出时间调短到 0.35 秒、
   停留时间 15 秒，方便边看边学。
3. 快捷键速查：点「帮助 → 快捷键速查」，打开已汉化的中文页面，
   含 60+ 组快捷键、鼠标操作与自定义方法。
4. 粒子特效教程：同目录下的「粒子特效中文教程.html」，双击用浏览器打开，
   含四种发射器对比、全部参数释义、六种效果配方、常见问题排查。
5. Blender 模式视口增强（rms-blender.jar）：
   · 修好了「视图 / 编辑 / 模型」三个页签来回切换越来越卡的毛病
     （原因是重绘定时器被停掉后没人重启；现在隐藏页签自动停、切回自动恢复）。
   · Blender 键鼠习惯：按住 Alt + 鼠标左键 = 旋转视口；Alt + 鼠标右键 = 平移视口；
     旋转轴心自动对齐到当前选中对象的包围盒中心。
   · 数字键盘全局生效（不用先点视口拿焦点）：
       Num1 前 / Num3 右 / Num7 顶 / Num9 反方向
       Num4 / Num6 左右转 15°（按住 Ctrl 则平移）/ Num2 / Num8 抬头低头
       Num5 切换正交 / 透视（原来是字母 O）
       Num. 聚焦选中物体 / Num0 重置缩放与位置
   · 视口背景改为 Blender 风格深灰渐变 + 自适应地面网格 + 红/绿/蓝三轴线；
     选中高亮改为 Blender 橙色。
   · 修复了本版本页签点击失效的问题：顶部「视图 / 编辑 / 模型」页签现在
     点文字即可正常切换（原版连点真正的页签都不生效，属于上游缺陷）。
   · Blender 惯例快捷键（数字行，不占用小键盘）：
       G = 移动 / R = 旋转 / S = 缩放 / E = 挤出（Blender 式：按 E 后
           新几何体直接跟随鼠标，左键确认、ESC 取消；G/R/S 变换才支持 X/Y/Z 锁轴，E/P 不支持）
       · 工具栏两个相邻按钮别搞混：
           挤出（EXTEND）= 真·挤出，拉出面时会生成连接侧壁（Blender 的 E）；
           分离面（EXTRUDE）= 把所选面从模型上「拔」出来，与原网格断开、
               不产生侧壁。E 键 = 挤出，P 键 = 分离面（均 Blender 式抓取交互）。
       1 = 点（顶点）选择 / 3 = 面 / 4 = 选择组   （2 预留给将来的「边」模式）
       编辑框、下拉框里打字时不会触发，Ctrl/Alt 组合键不受影响。
   · Blender 式抓取（新）：
       在模型页选中点 / 面 / 骨骼后按 G（或 R / S），所选元素直接跟随
       鼠标移动，无需按住鼠标键：
         移动鼠标      = 拖动所选
         X / Y / Z     = 锁定到对应轴（再按一次同轴解除约束）
         左键 或 回车  = 确认（进撤销栈，Ctrl+Z 可撤销）
         ESC 或 右键   = 取消，恢复原样
         小键盘        = 抓取过程中仍可转动视角
       旋转以所选中心为轴心，缩放同理。屏幕顶部会出现提示条显示
       当前模式与轴向。
   · 面选择修正：单击选面只保留离相机最近的面（原版会把点击射线
     穿透的背面一起选上）；线框显示模式下保留原版透选行为。
   · 全部以「配置 + 运行时注入」实现，没有改动原程序字节码逻辑。
6. 2K 屏 UI 全局放大（rms-blender.jar 内置）：
   · 启动后界面字体、工具栏图标、表格/树行高、分隔条整体放大 1.35 倍，
     之后打开的所有窗口（对话框、帮助页等）自动继承放大后的字体；
   · 想调大调小：右键「启动汉化版.bat」→ 编辑，在启动命令里加
       -Drms.ui.scale=1.5     （范围 1.0 ~ 3.0，改成 1.0 即恢复原大小）
     加在 -cp 参数之前、BlenderLauncher 之后的位置即可；
   · 想彻底关闭放大：把「汉化工具\blender\ScalingHooks.java」从构建脚本
     源码列表里删掉再重建，或直接改上面的倍率为 1.0。

【想自己改气泡文字】
打开同目录的「提示说明.txt」，每行格式：
      界面上显示的文字=中文说明||快捷键
  · "||" 后面是快捷键，可以省略；说明里用 \n 表示换行；
  · 菜单项本身带快捷键时，不写也会自动显示真实组合键；
  · 同一个文字写两次时，以靠后的一行为准；
  · 用 UTF-8 保存（记事本直接保存即可，也兼容 ANSI/GBK），重启程序生效。
每次启动还会生成「气泡注入报告.txt」，列出本次实际注入的中文说明，方便核对。

【想改快捷键】
编辑 → 偏好设置窗口 → 快捷键 → 编辑快捷键，选中动作后按下想要的组合键，
最后点「保存快捷键」。程序里可绑定的动作远多于菜单上显示的那些。

【关于英文残留】
模型数据关键字（附着点名、发射器内部名、MDL/MDX 字段名、贴图路径）
一律保留英文，这是保证导出的模型能被游戏和官方工具正确读取的硬性要求。
停靠窗口的少数按钮（Undock / Dock / Minimize / Maximize / Restore / Tab List）
来自第三方 InfoNode Docking 库，汉化版不改第三方字节码，但鼠标悬停时
会显示对应的中文说明气泡。

【回退 / 关闭增强】
把「rms-tooltips.jar」移走（例如改名），启动脚本会自动改用普通方式启动
原汉化主程序，界面汉化仍在，只是没有悬停说明气泡。
把「rms-blender.jar」移走，则再退掉 Blender 键鼠 / 渐变背景增强，
只保留界面汉化与气泡。想恢复，把文件名改回来即可。
想彻底回到出厂状态，「备份」文件夹里有替换渲染类之前的原始主程序
（RMS_zh_CN.jar.before-blender.bak）和你的原始偏好设置备份。

【目录里的东西】

  提示说明.txt               可编辑的气泡说明表

  粒子特效中文教程.html      粒子特效教程

汉化工具在上级目录的「汉化工具」文件夹里：
  词典源.txt / 汉化词典.json      汉化词条

【常见任务速查】
  看不到动画 / 时间轴是灰的
      时间轴默认禁用，连播放按钮都不显示。按 A 进入「动画」模式 → 动画下拉框
      选序列（显示 (Unanimated) 就是模型本身没有动画）→ Ctrl + 空格 播放。
      「视图」菜单里的「渲染粒子」要勾选，否则粒子不显示。

  把一把剑挂到手上
      路线 A（游戏侧挂载，WC3 标准做法）：添加 → 附着点 → 名字必须是标准英文
      （Hand Right / Weapon / Hand Right Ref，写中文游戏端识别不了）→ 把父级
      设成手部骨骼。剑模型不塞进本软件，由单位数据或 MDL 的 Path 在游戏里
      按附着点名挂上去。数据层有 path 字段，但界面没有对应输入框。
      路线 B（把剑网格真正并进当前模型）：工具 → Twilac 实验工具 → 导入模型部件，
      选 .mdx/.mdl，在 Parent 里选手部骨骼（只能选骨骼，不能选附着点）→ 导入！。
      另：文件 → 导入(Ctrl+Shift+I) 也能合并组件/动画，但结果会开一个新窗口。

  给剑做丝带刀光
      添加 → 粒子 → 空丝带粒子（Ribbon）→ 空丝带不弹父级框、默认在原点，需去
      节点树把它挂到武器/手部骨骼，并给它位移动画（没有位移动画就没有拖尾）
      → 选中丝带，在「模型组件」面板调上方/下方高度（拖尾宽度）、生命周期、
      发射速率、重力、颜色、不透明度 → 材质换「叠加」+ 带渐变 Alpha 的贴图
      → 可见性关键帧只在挥砍帧设为 1（0 隐藏，1 显示；编辑器视口显示阈值 0.75）。
      注意：编辑视口不渲染丝带拖尾，必须导出进游戏才看得见。
      完整配方见「粒子特效中文教程.html」的「刀光拖尾」。

  实时绘制纹理
      本软件没有画笔。唯一路径：工具 → 编辑贴图 → Export 导出 → 用 PS/GIMP/BLP
      工具在外部绘制 → Replace / Add 导回（或改 Apply Path 指向新文件）。
      「工具 → 编辑 UV 映射」只改 UV 坐标，不改像素；UV 视口里的 Load Image
      只是垫在背后的参考图，画上去的像素不会保存。

  挤出 / 分离面后新面和点选不中
      已修复：生成新几何后会同步 ModelView 的可编辑顶点缓存，并自动选中新顶点。
      若仍遇到，请确认使用的是最新版 RMS_zh_CN.jar。

  这些功能确实没有（不是没找到）
      实时绘制纹理、丝带拖尾的视口预览、建模页高级工具（环切/倒角/细分/布尔/
      镜像/软选择）、局部坐标轴锁定。
      详见软件内「帮助 / 快捷键说明」的第七至十节。
